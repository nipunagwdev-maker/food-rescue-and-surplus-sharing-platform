# ShareBite

**Food Rescue and Surplus Sharing Platform**

> Share extra, waste less.

ShareBite connects people who have extra food (shops, bakeries, hotels, homes, events) with people and charities who need it. The goal is simple: good food should be eaten, not thrown away.

## About the Project

Every day, a lot of good food is thrown away while many people go hungry. For example, a bakery may have 20 fresh buns left at 7 PM that it cannot sell tomorrow. With ShareBite, the baker posts the buns, someone nearby claims them, and the food gets eaten instead of wasted.

This project is a group project developed as part of our university studies.

## Features

- Post surplus food with the name, amount and pickup time
- Browse available food near you
- Claim and collect food
- Track how many meals have been saved

> Note: The current version is the landing page. Other features will be added step by step.

## How It Works

1. **Post it:** A donor adds the extra food and the pickup time.
2. **Claim it:** People and charities nearby see the post and claim what they need.
3. **Pick it up:** They collect the food before the time ends.

## Getting Started

### Run it on your computer

1. Clone the repository:
   ```bash
   git clone https://github.com/nipunagwdev-maker/food-rescue-and-surplus-sharing-platform.git
   ```
2. Open the project folder:
   ```bash
   cd food-rescue-and-surplus-sharing-platform
   ```
3. Open `index.html` in your browser. No installation is needed.

### Make a change

1. Edit the files in any code editor (for example VS Code).
2. Save and refresh the browser to see the result.
3. Commit and push your changes:
   ```bash
   git add .
   git commit -m "Describe your change"
   git push
   ```
